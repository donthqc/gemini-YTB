# FlowStory AI - Batch Generator for Google Flow

Tiện ích mở rộng Chrome hỗ trợ tự động phân tách kịch bản dài thành các phân cảnh tuần tự (giữ nhất quán nhân vật chính) và tự động tạo ảnh/video hàng loạt trên Google Flow.

## Tính năng chính
- 🧠 **Auto-Prompting:** Sử dụng Gemini API tự động trích xuất nhân vật (Character DNA) và tạo prompt điện ảnh tuần tự.
- 👤 **Nhất quán nhân vật:** Khóa diện mạo nhân vật qua toàn bộ các cảnh trong truyện.
- 🎬 **Hỗ trợ Video & Ảnh:** Sinh đồng thời cả Image Prompt và Motion Prompt (cho Veo 3.1 / Gemini Omni Flash).
- ⚡ **Tự động hóa trên Google Flow:** Tự động điều khiển hàng đợi tạo ảnh trên giao diện `flow.google.com`.

## Cài đặt trên Chrome
1. Tải về và giải nén thư mục này.
2. Mở trình duyệt Chrome, truy cập: `chrome://extensions/`
3. Bật **Chế độ dành cho nhà phát triển** (Developer mode).
4. Bấm nút **Tải tiện ích đã giải nén** (Load unpacked) và chọn thư mục `flow-story-extension`.
